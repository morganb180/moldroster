# Contact Mold Roster

Mold Roster is a small independent directory and guide. We read every message. We aren't a contractor, inspector or government agency, and we can't do mold inspection or removal work ourselves.

## Email

[hello@moldroster.com](mailto:hello@moldroster.com): questions, data corrections and advertising. When writing about a specific listing, please include its listing ID (for example TX0001).

## Listings

To claim, correct, add or remove a listing, use the [listing request form](https://moldroster.com/claim-listing/).

See the [privacy policy](https://moldroster.com/privacy/).
